# 判据核对清单 · dual-simulation-gate

对每次待决事项，逐条打勾；任何 ✘ 即不达标。

## 六判据（改动面）

- [ ] 1. 可逆可回滚：动了什么？回滚方案写明了吗？
- [ ] 2. 只增不覆盖：会覆盖/删除既有版本、档案或配置吗？
- [ ] 3. 零资金流出：产生任何付费消耗吗？
- [ ] 4. 不动封存版本：触碰已参评/已锁档历史版本吗？
- [ ] 5. 不挤占硬节点：占用主线关键交付（deadline）的窗口与资源吗？
- [ ] 6. 无新增第三方数据出口：新增把数据送出边界的通道吗？

## 三面标尺（执行与联通）

**架构面**
- [ ] 单点不信任：新组件会否成为唯一依赖？
- [ ] 复用融合不破坏：是否独立部署、不碰旧部署？
- [ ] 指数退避：故障时退避等待而非硬撞？
- [ ] 幂等去重：重复执行无副作用？
- [ ] 一键恢复：部署/回滚脚本幂等且可一键执行？

**执行面**
- [ ] 凭证资源优先复用：不重复索要/新建已有资源？
- [ ] 一步到位：前置确认清单一次核验，零占位符交付？
- [ ] 闭环验证：结果有回读/实测环节？
- [ ] 被纠正即固化：纠错沉淀为规则/脚本，不靠记忆？

**联通面**
- [ ] 先验通道再试错：通道实测通过才进实施？
- [ ] 闭环可读：指令下发与结果回传双向验证？

## 放行条件

- 六判据全 ✔ **且** 三面标尺无未决 ✘ **且** 两轮推演结论一致；
- 结论不一致、或任何 ✘ 无法当场化解 → 升级拍板；
- 达标但带注意点 → 写明附条件，逐条核验后放行。
